THE MEASUREMENT LOOP

Predict. Probe. Adapt.

Actual local parameter updates, with every requested label accounted for.

01 / PREDICT

Start with a trained model.

A ridge predictor maps the released sensor features to a metrology target. Feature and context residual adapters track change. The base method is GRAPE, credited below.

02 / PROBE

Respond to surprise.

When a requested measurement differs strongly from the prediction, the schedule asks again sooner. Stable measurements gradually extend the interval, up to ten samples.

03 / ADAPT

Update locally.

Only measured outcomes update the lightweight residual state. The portable runtime uses NumPy and exported trained parameters; there is no LLM API in the inference path.

First commercial hypothesis: CMP process-development and consumables teams that repeatedly recalibrate models after changes. Next evidence needed: delay-aware adaptation, a fresh customer holdout, true maintenance records and measured engineering-time savings.
