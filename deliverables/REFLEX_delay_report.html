무엇을 실제로 바꿨나

  1. 원래 샘플 시각을 보존했다. 늦게 도착한 라벨을 현재 시각의 측정인 것처럼 처리하지 않는다. 현재 구현은 고정 지연과 순서가 유지되는 도착을 다루며, 가변 지연·역순 도착은 별도 검증 대상이다.
  2. 서로 다른 상태 추정기를 유지한다. 기존 GRAPE, 원시각 기준 Kalman 잔차 추정, 베이지안 공정 변화 가설을 동시에 갱신한다. 급변 대응만 강하게 하면 잡음이 큰 데이터에서 악화되는 것을 실제로 확인했다.
  3. 도착한 측정값으로만 모델 비중을 학습한다. 샘플을 처음 예측했을 때의 각 모델 출력을 저장하고, 나중에 실제 라벨이 도착하면 그 오차로 가중치를 갱신한다. 평가 정답을 미리 보고 좋은 모델을 고르지 않는다.
  4. 변화 가설의 계산량을 제한했다. 베이지안 구성요소를 최대 32개로 제한하고 유사한 Gaussian 사후분포를 모멘트 보존 방식으로 합친다. 이는 전체 시스템의 모든 메모리가 상수라는 뜻은 아니다. UI 이력과 장비 문맥 상태는 별도로 증가한다.

검증과 실패 이력

원래 train으로 적합한 회귀 모델은 유지했다. 하이퍼파라미터는 valid+test 및 미리 정의한 급변·펄스·램프 합성 변화로 조정했다. 후보 선택에 평가 데이터를 직접 사용하지 않았지만, 평가 실패를 확인하며 모델 계열을 변경했으므로 새 블라인드 검증으로 볼 수 없다.

  • v4 시간 보정 Kalman: 데이터셋 1의 큰 변화에 느려 실패.
  • v5 변화 감지 후 재설정: 데이터셋 1은 개선, 데이터셋 2는 잡음 때문에 악화.
  • v6 베이지안 변화 모델 단독: 데이터셋 1 지연 5에서 RMSE 8.86%, P90 14.64% 개선. 데이터셋 2 지연 5 RMSE는 3.32% 악화. 범용 모델로 채택하지 않았다.
  • v7 도착 라벨 기반 통합: 위 표의 결과. 가장 좋은 데이터셋별 모델을 사후 선택한 수치가 아니다.

새 검증 7개: Kalman 식과 명시적 행렬 계산의 일치, 베이지안 짧은 스트림과 전체 분할 열거 결과의 일치, 극단 입력에서도 유한한 출력과 32개 가설 제한, 미요청 라벨 불변성, 라벨 도착 전 예측 불변성, 통합 모델의 미래 라벨 차단, 두 데이터셋·세 지연·다섯 시작 위치 전체에서 배포 런타임과 잠근 평가 출력의 일치. 원래 런타임 검증 3개도 유지한다.

심사위원에게 제안할 정확한 문장

“REFLEX는 계측 결과가 늦게 돌아오는 반도체 공정의 로컬 보정 모델입니다. 샘플 시각과 측정 도착 시각을 구분하고, 도착한 오차로만 보정 모델의 비중을 학습합니다. 공개 데이터 한 조건에서 추가 측정 없이 P90 오차를 12% 줄였고, 다른 조건과 실패 결과도 함께 공개했습니다.”

주장은 ‘특정 지연 조건의 오차 감소’까지다. 웨이퍼 수율 향상, 공장 비용 12% 절감, 모든 공정에서 12% 개선, 세계 최초 알고리즘, Bagel 완전 재현은 현재 자료로 뒷받침할 수 없다.

사업을 뾰족하게 만드는 다음 계약

첫 고객 가설은 반도체 공정개발팀 또는 장비·소모품 업체 응용개발팀이다. 장비군 하나, 품질 타깃 하나, 샘플 시각·계측 완료 시각이 있는 신규 스트림으로 유상 검증을 제안한다. 가격은 500만~1,000만원 파일럿, 검증 후 2,000만~5,000만원 통합이라는 제안 가설이며 지불 의향을 확인하지 않았다.

파일럿의 판정 항목은 고정 계측 예산의 전체 RMSE·P90·규격 초과 누락, 실제 지연별 성능, 재보정 엔지니어 시간이다. 현재 데이터에는 충분한 불량 규격·실제 계측 지연·비용 정보가 없으므로 그 절감액을 계산하지 않았다. CMP는 초기 고객 탐색 후보지만, 새 GRAPE 결과가 CMP 특정 공정의 성능임을 확인한 것은 아니다.

잠재적 해자는 재사용 권한이 있는 공정 전환 데이터와 검증된 장비 어댑터다. 공개 회귀·Kalman·변화점 탐지·온라인 가중합 자체를 독점 기술이라고 포장하지 않는다. 반복 도입에서 신규 공정의 초기 측정 수와 통합 시간이 줄어들어야 확장성이 입증된다.
